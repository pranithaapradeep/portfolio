GitHub repositorygithub.com/pranithaapradeep

AI-Powered Blockchain Fraud Detection

An AI-powered fraud detection system designed to identify suspicious patterns in Ethereum blockchain transactions and wallet behaviour.

The project uses machine learning to analyse transaction-related behavioural features and predict potential fraudulent activity. An XGBoost classification model is used to assess wallet risk based on historical transaction patterns. It also incorporates behavioural drift detection to identify changes in wallet activity over time. Graph-based risk analysis helps explore indirect associations between wallets and suspicious transaction networks. A dynamic wallet trust scoring mechanism combines risk indicators to support more explainable risk assessment and decision-making.
